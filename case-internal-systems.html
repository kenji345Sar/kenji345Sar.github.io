社内業務の効率化・連携対応

期間: 約9ヶ月 体制: 全体3名 使用技術: Laravel 8 / PHP / kintone / desknet's / VBA / JavaScript / Oracle / MySQL / CentOS

案件概要

9ヶ月の期間中、性質の異なる4つの業務テーマを並行で担当。 Laravel API による開発、kintone でのローコード開発、VBA によるデータ処理、 PHP4 / Oracle のレガシー保守まで、9種類の技術・製品を用途に応じて使い分けながら進めた案件です。

担当した4つの業務テーマ

  • 事業部門管理資料のバッチ処理化 — API 作成は Laravel、フロント側は VBA で対応
  • 経費精算システムの見直し — Desknet's と kintone の連携
  • 押印簿対応 — 紙での稟議・契約書運用を kintone に組み込み
  • 既存レガシーシステムの保守 — PHP4 / Oracle

発揮した技術の幅

1案件の期間中に、性質の異なる4つのレイヤを同時に扱いました。

  • モダン Web 開発：Laravel 8 による API 開発と外部システム連携
  • ローコード：kintone でのアプリ構築・既存運用への組み込み
  • 業務補助：VBA によるデータ処理自動化、Excel 連携
  • レガシー保守：PHP4 / Oracle の継続運用対応

「モダン × ローコード × VBA × レガシー」を 1 名で横断できる人材は中小企業の現場で希少で、 ベンダー分割発注を 1 本にまとめられる強みになります。

習得・活用したスキル

  • Laravel による API 開発と外部システム連携
  • kintone によるローコード開発
  • VBA によるデータ処理自動化

この経験から提供できること

  • 既存パッケージ（Desknet's / kintone 等）と既存業務を活かしたまま、足りない部分を API・連携で埋める
  • 紙運用や Excel 運用を、ローコード（kintone）に乗せ替える
  • レガシーシステム（PHP4 / Oracle 等）の保守と、新規開発を並行で進める
  • 1 つの契約の中で、複数の業務テーマを横断的に担当する

所感

API・バッチ処理による Excel 対応を経験し、ローコード開発や外部システム連携の有効性を実感した案件です。
